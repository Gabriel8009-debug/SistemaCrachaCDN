SISTEMA DE CRACHÁS CDN — GERADOR DO EXECUTÁVEL

OBJETIVO
Gerar a versão oficial do sistema para Windows, em formato .exe.

PASSO MAIS RÁPIDO

1. Extraia este ZIP.
2. Execute:
   INSTALAR_GERADOR.bat
3. Abra:
   C:\SistemaCracha
4. Execute:
   GERAR_EXE.bat
5. Aguarde a compilação.

RESULTADO

A aplicação será criada em:

C:\SistemaCracha\dist\SistemaCrachaCDN\SistemaCrachaCDN.exe

IMPORTANTE

O PyInstaller gera uma pasta de aplicativo. Para usar ou transferir o sistema,
mantenha a pasta inteira:

C:\SistemaCracha\dist\SistemaCrachaCDN

Não copie somente o arquivo .exe, pois ele depende dos arquivos internos da pasta.

CREDENCIAIS

A pasta credentials permanece externa ao executável e será copiada para a
pasta final. Isso permite substituir credenciais sem recompilar.

PRIMEIRA ABERTURA

O Windows pode exibir a proteção do SmartScreen porque o executável não possui
certificado digital pago. Nesse caso:

1. Clique em "Mais informações".
2. Clique em "Executar assim mesmo".

Isso é diferente de um erro do sistema. Para eliminar esse alerta completamente,
seria necessário assinar o executável com um certificado de assinatura de código.

ATALHO

Depois de testar o aplicativo, clique com o botão direito em
SistemaCrachaCDN.exe e escolha:

Enviar para > Área de trabalho (criar atalho)
